Sync across phone and PC

One-time setup. Use the same cloud project and account on both devices.

Important: Sync needs a cloud project and internet at least when signing in/syncing. The app can still work locally when offline, then upload changes later. Do not put a database service-role key here.

1. Connect Supabase

Create a free project at supabase.com. In Project Settings → API, copy the Project URL and publishable/anon key. Paste them below. Your data is protected per account using row-level security.

These settings are stored only in this browser. Enter them separately on each device.

2. Sign in on this device

Use the same account on your phone and PC. Depending on your Supabase email settings, creating an account may require email confirmation.

3. Create the secure database table

In your Supabase project, open SQL Editor, paste the contents of supabase-schema.sql from the downloaded project, and run it once. Then sign in above and press Sync now.

The project ZIP includes supabase-schema.sql. It creates one private JSON backup row per signed-in user and enables row-level security so each account can only access its own data.

Maths Reps stores your local data on this device. Cloud sync is optional and only activates after you configure it. Export backups before clearing browser data.
